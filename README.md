## Lab 05 - Product Management System

This lab implements a simple product management system using Java. It demonstrates object-oriented programming concepts including classes, objects,
constructors, constructor overloading, static data members, and member functions.

### Project Files

* `Product.java` - Defines product attributes and operations, including product ID, name, price, quantity, and manufacturing date.
* `Date.java` - Represents manufacturing dates and provides a formatted date using `toString()`.
* `Demo.java` - Creates product objects and demonstrates their functionality.

### Key Features

* Automatic generation of unique product IDs.
* Storage of product name, price, and quantity.
* Tracking of minimum and maximum product prices.
* Support for product manufacturing dates.
* Formatted display of product information.

## Concepts Covered

* Classes and Objects
* Constructors
* Constructor Overloading
* Static Data Members
* Member Functions
* Encapsulation
* `toString()` Method
* String Formatting

## Run Instructions

Compile the Java files:

```bash
javac Lab05/*.java
```
